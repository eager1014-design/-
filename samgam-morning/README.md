# 삼감 모닝 (Samgam Morning)

매일 아침 20분: 감사 3분 → 감동 10분 → 감탄 4분 → 오늘의 실행 3분.

## 실행하는 법
1. Finder에서 `samgam-morning` 폴더를 엽니다.
2. `start.command`를 더블클릭합니다.
   - 처음 한 번은 "확인되지 않은 개발자" 경고가 뜰 수 있어요 → 파일을 **오른쪽 클릭 → 열기 → 열기**를 누르면 됩니다.
3. 브라우저가 자동으로 `http://127.0.0.1:8790`을 엽니다.
4. 끝내려면 함께 열린 터미널 창을 닫으면 됩니다.

추가로 설치할 프로그램은 없습니다. (맥에 원래 있는 Python만 씁니다)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 내용 |
| `style.css` | 색과 디자인 |
| `start.command` | 더블클릭 실행기 |

## 진행 상황
- [x] 1단계: 첫 화면 (제목, 디자인, 20분 구성 표시)
- [ ] 2단계: 시작 버튼 + 20분 타이머 + 다음 단계 버튼
- [ ] 3단계: 단계별 음악/유튜브 URL 등록, 재생·일시정지
- [ ] 4단계: 오늘의 가장 중요한 일 입력·저장
- [ ] 5단계: 로그인 시 자동 실행, 정해진 시간 예약 실행

화면에서 회색 점선 버튼과 "준비 중" 표시는 아직 작동하지 않는 기능입니다.
