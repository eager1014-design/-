# Workflow: 홍보 (스레드 · 인스타그램 · 당근)

## 목표
매일 홍보 글을 꾸준히 올려서 신청서로 손님을 데려온다. 어느 채널이 돈이 되는지 숫자로 보고 거기에 힘을 준다.

## 필요한 입력
- (선택) 스레드에서 반응 좋은 사주 글 몇 개 — '참고할 인기 글'에 붙여넣기
- 스레드 연결 토큰 (자동 게시를 쓸 때만)

## 누가 무엇을 (2026-10-19 사장님 결정)
- **제미나이 = 분석**: 참고 인기 글 + 우리 글 성적(조회·좋아요·댓글)을 보고 '오늘의 글쓰기 메모'
- **클로드 = 글쓰기**: 맥북의 Claude Code 구독(`claude -p`)으로 메모를 보고 5개 작성 → 추가 API 비용 없음
- 맥북이 꺼져 있던 날은 서버의 AI(제미나이)가 10시에 대신 씀

## 사용할 Tool
- 매일 아침 글쓰기: `tools/threads_daily.py` (7:30 자동 실행: `tools/threads_daily.plist`, 기록 `.tmp/threads_daily.log`)
  - 시험: `python3 tools/threads_daily.py --dry-run` (서버에 안 넣고 화면에만)
  - 설정: 루트 `.env`의 `SAJU_URL`(서버 주소), `SAJU_ADMIN_KEY` = `saju/.env`의 `ADMIN_API_KEY
- 홍보 센터 화면: `/admin#/promo`
- 글 후보 만들기·채널 집계: `saju/promo.py` (글 규칙·주제는 이 파일의 `CHANNELS`, `THEMES`, `PERSONA`)
- 스레드 게시: `saju/threads.py` (메타 공식 API)

## 순서 (매일 10분)
1. (스레드) 매일 7:30 맥북의 클로드가 후보 5개를 넣어 둠. 홍보 센터의 **'매일 아침 자동'**을 켜두면 맥북이 못 한 날 10시에 서버가 대신 씀
   직접 만들려면 `/admin#/promo` → 채널·주제 고르기 → **글 후보 5개 만들기** (AI 유료 호출 1회, 몇 원)
   - 주제에서 '상품 홍보 시리즈'(예: 신년운세 시리즈)를 고르면 그 상품으로 이어지는 글 + 그 상품이 골라진 링크
2. 마음에 드는 글만 고치기. 나머지는 **버리기**
3. 스레드(연결됨): **예약하기** → 비어 있는 다음 시간대(기본 12:30 · 21:00 · 22:30)에 자동 게시 + 첫 댓글에 신청서 링크
   급하면 **지금 올리기**. 예약은 '예약 취소'로 되돌릴 수 있음 (서버가 켜져 있어야 예약 게시됨)
   스레드(미연결)·인스타·당근: **복사** → 앱에 붙여넣기 → 올린 뒤 **올렸어요**
4. 일주일에 한 번 '어디서 손님이 오나요' 표 확인 → 신청·입금이 많은 채널에 글을 더 쓴다

## 글 쓰는 원칙 (2026-10 조사 반영)
- 스레드는 하루 1~3개, 평일 밤 9~11시가 반응이 좋다는 자료가 많음
- 잘 되는 주제: 연애·끌림, '이런 사람 특징' 자가진단, 신살(도화살·양인 등), 띠·일간별, 절기 기운
- 본문에서 팔지 않는다. 판매는 프로필 링크와 첫 댓글 링크로. 상품 소개 글은 5개 중 1개 이하
- 시리즈로 쓴다: ① 공감 장면 + 사주 해석 → ② 다음 글 "내 일간으로 확인하는 법" → 댓글 참여
- 공개 댓글로 생년월일을 받지 않는다(개인정보). 일간·띠 정도만
- 없는 경력·숫자·후기 금지 (계정 신뢰·정지 위험)

## 채널별 링크 (프로필·글에 이 링크를 써야 집계됨)
- 스레드 `주소/?src=threads` · 인스타 `주소/?src=instagram` · 당근 `주소/?src=daangn`
- 상품을 미리 골라두려면 `&p=match` 처럼 붙임 (full·yearly·match·counsel)

## 스레드 연결 (처음 한 번, 사장님 + 신입)
1. 스레드 계정을 '운결' 브랜드로 정리: 프로필 사진, 소개("사주로 보는 커리어·관계 코칭"), 링크 = `주소/?src=threads`
2. developers.facebook.com → 앱 만들기 → 사용 사례 'Threads API 액세스' → 권한 `threads_basic`, `threads_content_publish`, `threads_manage_insights`(성적)
3. 테스터에 내 스레드 계정 추가 → 스레드 앱 설정에서 초대 수락 → 토큰 발급 → **장기 토큰(60일)**으로 교환
4. `saju/.env` 에 `THREADS_ACCESS_TOKEN=...` → 서버 재시작 → 홍보 센터 '연결 확인'
- 이후 토큰은 서버가 만료 10일 전에 스스로 연장(DB에 보관)
- 남의 공개 글 키워드 검색(`threads_keyword_search`)은 메타 앱 심사 통과 후에만 가능 → 그 전에는 '참고할 인기 글'에 직접 붙여넣기

## 설정 (saju/.env, 선택)
- `THREADS_POST_TIMES=12:30,21:00,22:30` 게시 시간대 / `THREADS_DRAFT_HOUR=8` 아침 후보 만드는 시각
- `THREADS_LINK_TEXT=…{link}…` 첫 댓글 문구

## 문제가 생겼을 때
- 아침 후보가 없음 → `.tmp/threads_daily.log` 확인. '서버 연결 실패'면 SAJU_URL·서버 상태, '클로드 글쓰기 실패'면 터미널에서 `claude` 로그인 상태 확인
- 우리 글 성적(조회·좋아요)이 안 쌓임 → 메타 앱에 `threads_manage_insights` 권한 추가 필요
- 예약 글이 안 올라가고 후보로 돌아와 있음 → 글 아래 빨간 글씨가 실패 이유. 고친 뒤 다시 예약
- "Invalid OAuth 2.0 Access Token" → 토큰 만료·오타. 새 장기 토큰을 발급해 `.env`에 넣고, DB에 남은 예전 토큰은 `kv` 표의 `threads_token` 줄을 지운다
- 게시 실패 후 다시 누르면 같은 글이 두 번 올라갈 수 있음 → 스레드 앱에서 먼저 확인
- AI 답변이 글 목록 모양이 아니면 기본 글로 대체됨 (서버 기록에 `[홍보]` 로 남음)
