# Workflow: 가게 방문 상담 (자동화 대행)

## 목표
가게 한 곳을 다녀와서 "제일 귀찮은 일 1개 + 일주일에 드는 시간 + 만들 수 있는지 + 견적"이 정리되고, 사장님(손님)께 이틀 안에 연락이 간다.

## 필요한 입력
- 사장님(천성준)이 방문 후 말해 주는 것: 가게 이름·업종, 진단 질문 답(특히 지금 쓰는 프로그램, 일주일에 몇 시간), 찍은 사진·녹음
- 떡상 앱 '고객 고충' 탭에 들어온 폼 내용 (있으면)

## 사용할 Tool / 자료
- 사장님용 설명서(Claude 문서): https://claude.ai/artifact/R6YZHkF62SufYUThWTm5n8 — 현장 순서, 질문, 견적 말하는 법
- 동의서(Claude 문서, 인쇄용): https://claude.ai/artifact/5XkfgSBhHviyovFyw3Veji
- 떡상 앱 '고객 고충' 탭 (http://localhost:4600) — 처리 단계·메모. 시트 읽기는 `tools/needs_form.mjs` (token_finance, 7일마다 만료 → `tools/finance_login.command`)
- 포트폴리오: https://claude.ai/artifact/HfrXKBoNL643BggQ1Tpy8n (맨 위 홍보 영상, '처음 3곳 무료 · 상담 후 견적 · 첫 3개월 관리 무료')

## 순서 (사장님이 "오늘 다녀온 가게 정리해줘" 하면)
1. 고객 고충 탭에서 그 가게를 찾고(없으면 사장님 말로) 답을 정리한다: 귀찮은 일, 지금 쓰는 프로그램, 일주일 시간
2. **이미 있는 프로그램이 하는 일인지 먼저 확인** (캐시노트·배달앱 사장님 화면·포스 리포트 등). 그렇다면 만들지 말고 "그 기능 쓰는 법"을 알려 드리는 게 답이다
3. 만들 수 있는지 판단: 사장님이 이미 쓰는 구글 시트·메일·폰에서 돌아가게. 매달 AI 사용료가 손님 쪽에 나가는 구조는 피한다
4. 걸릴 시간 어림 + 견적 (아래 기준, 처음 3곳은 무료)
5. 사장님이 보낼 연락 문구 초안: 감사 인사 + 만들 것 한 줄 + 견적(또는 무료 안내) + 시간을 돈으로 바꾼 한 문장
6. 고충 탭 처리 단계를 바꾸라고 알려 드린다 (연락함 → 미팅 잡음 → 만드는 중 → 완료/보류)
7. 실제로 걸린 시간(방문·제작·수정)을 기록해 두게 한다 — 가격 확정 근거

## 견적 기준 (공개하지 않음, 2026-10-24 사장님 결정)
| 상품 | 기준 |
|---|---|
| 30분 방문 진단 | 무료 |
| 작은 자동화 1개 | 15만~30만 원 |
| 여러 개 연결 | 50만~100만 원 |
| 관리 | 첫 3개월 무료, 4개월째부터 원하는 분만 월 2만~3만 원 |
- 근거: 크몽 시트 자동화 3만~33만 원대. 설득 문장 = "매주 3시간 × 시급 1만 원 = 월 12만 원, 20만 원이면 두 달에 본전"
- 처음 3곳 무료. **무료 조건에 촬영 동의를 걸지 않는다** (동의서의 '거부해도 불이익 없음'과 충돌)
- 처음 3곳 기록을 보고 금액 확정. 첫 유료 손님 전 사업자등록 필수

## 결과물
- 사장님께: 정리 + 연락 문구 초안 (채팅)
- 고객 고충 탭 메모 (사장님이 저장)

## 문제가 생겼을 때
- 고충 탭이 시트를 못 읽음 → token_finance 만료. `tools/finance_login.command` 더블클릭 안내
- 사장님이 현장에서 "다 됩니다"라고 약속해 버림 → 만들 수 있는 범위로 줄인 안을 같이 보내고, 안 되는 부분은 솔직하게
- 손님이 영상 삭제를 요청 → 7일 안에 내리고 동의서 파일 옆에 날짜 기록
