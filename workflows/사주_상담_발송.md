# Workflow: 사주 상담 판매 · 풀이 발송

## 목표
손님 신청 → 입금 확인 → 풀이 작성·수정 → PDF를 손님 이메일로 발송. 사장님 혼자 하루 몇 건씩 처리할 수 있게.

## 필요한 입력
- 손님 신청 (사이트 첫 화면 신청서, 또는 카톡·DM으로 받은 정보)
- 사장님 통장 입금 내역 (입금자명 = 신청자 이름)

## 사용할 Tool (모두 `saju/` 서버 안)
- 신청서: `saju/static/apply.html` (주소 `/`, 채널 추적 `/?src=threads`)
- 관리 화면: `saju/static/admin.html` (주소 `/admin`, `ADMIN_EMAIL` 계정만)
- 신청 저장: `saju/orders.py` / 풀이: `saju/interpret.py` / PDF: `saju/pdf_report.py` / 메일: `saju/mailer.py`

## 설정 (saju/.env, 처음 한 번)
| 이름 | 뜻 | 예 |
|---|---|---|
| `ADMIN_EMAIL` | 사장님 로그인 이메일. 이 계정만 관리 화면·가입 가능 | eager1014@gmail.com |
| `BANK_ACCOUNT` | 손님에게 보여줄 입금 계좌 | 카카오뱅크 3333-00-0000000 홍길동 |
| `PRICE_<상품키>` | 상품 가격(원). 상품키: counsel·love·pet·reunion·match·career·full·newyear·life | `PRICE_NEWYEAR=12900` |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` | **맥북의 `saju/.env`에만.** Gmail smtp.gmail.com / 587 / 주소 / **앱 비밀번호**. Railway(Hobby)는 메일 포트가 막혀서, 서버는 보낼 메일을 보관함에 넣고 맥북 일꾼이 Gmail로 대신 보냄 | |
- 사장님 계정 만들기: `/admin#/signup` 에서 `ADMIN_EMAIL` 주소로 가입 (다른 주소는 가입 거절됨). 예전 구독 앱 `/app` 은 닫힘
- 비밀번호를 잊으면: 신입이 맥북에서 `/api/admin/owner-reset`(비밀 열쇠 필요)으로 '새 비밀번호 정하기' 링크 발급
- **PDF는 언제나 유료 (사장님 결정 2026-10-20 밤)**: 무료는 사이트의 짧은 풀이뿐. 첫 1회 무료 PDF(`FREE_FIRST=1`)·친구 초대 무료 PDF(`REF_FREE=1`)는 기본 꺼짐. **평생 종합 사주(34,900원)·월 구독은 무료 대상 아님** (products.py `no_free`)
- **첫 화면 흐름 (2026-10-20 밤 개편)**: 웹툰 → '선택해라'(밖의 5만 원 vs 너와 이야기하는 운결, 구독 이야기 없음) → 생년월일 → **성향·오행·올해·오늘** → 상담 주제 6개 버튼 → **맨 끝에 '매일 아침' 구독**
- **도령의 상담실 `/consult`** (`saju/consult.py`, `static/consult.html·js`): 고민상담·연애운·재회·궁합·직업재물·반려동물. 도령이 2~3가지를 묻고(고르기) + 손님이 한 줄 → 서버 AI(제미나이, 25초 넘으면 규칙 문장)로 상담: 핵심 · 이렇게 해라 · **더 깊이(진짜 이유와 움직일 때) — 잠그지 않고 다 보여줌**. 궁합은 상대 생년월일 필수, 재회는 선택, 반려동물은 아이 생일. 상담 내용은 저장 안 함
- **친구에게 보내면 PDF 1개 무료** (사장님 결정 2026-10-20 밤): 상담실의 링크(`/?inv=방문자번호`)로 온 친구가 **실제로 자기 사주를 보면**(첫 화면 바로 보기 또는 상담실), 링크 주인의 상담실 화면에 'PDF 무료로 받기'가 열림 → 이름·이메일만 쓰면 무료 신청(관리 목록 '친구 초대 무료'). **가벼운 풀이 6종만**, 1인 1회(방문자번호·이메일 기준, `invite_pdf`). 신년·기본·평생 종합·구독은 유료
- **비싼 PDF 친구 할인** (사장님 결정 2026-10-20 밤): 같은 친구 방문으로 평생 종합 9,900원 / 기본 사주·신년운세 10% 할인(`products.friend_discount`). 할인은 1인 1회(셋 중 하나), 무료 신청엔 안 붙음. 관리 목록에 할인 금액 표시
- **페이지 넘김**: 첫째 장(이야기) → 둘째 장(너는 이런 사람이다) → 셋째 장(상담실 대화) → 넷째 장(PDF 받기·친구 혜택·더 깊은 PDF·맨 끝 구독). 섹션이 끝나면 막이 내려왔다 올라감(`form.js turnPage`)
- **목소리 자리**: n14(중간 '선택해라'), q01(둘째 장 끝), c01~c07(상담실). `static/voice/<id>.mp3` 를 넣기만 하면 그 장면에서 나옴(없으면 조용히 넘어감). 대본은 `video/public/episodes/ungyeol-dory/대본_일레븐랩스.txt`. 한 파일로 만들어 오면 문장마다 잘라야 하는데, 쉬는 구간만으로는 못 나눠서 받아쓰기(제미나이)가 필요 — 줄마다 따로 만들면 자를 필요 없음
- 친구 초대: 손님마다 초대 링크(`/?ref=코드`). 처음 온 친구가 신청하면 링크 주인에게 무료 1회 (최대 10회 적립)

## 순서
0. **자동 시작**: 무료 신청은 들어오는 순간, 유료는 '입금 확인'을 누르는 순간 풀이가 맥북 챗GPT 대기열에 자동으로 들어감 (`AUTO_GENERATE=off`로 끔). 사장님은 다 쓰인 풀이를 읽고 '손님에게 보내기'만
1. 새 신청 알림 메일이 오면 `/admin` → 신청 목록에서 '입금 대기' 확인
   - **첫 1회 무료** 손님(이메일 또는 이름+생년월일 기준 처음)은 금액 '무료', 바로 '입금 확인' 상태로 들어옴 → 3번부터
2. 통장에서 입금 확인 → 신청 열고 **입금 확인**
3. **풀이 만들기** → 상품 목차의 장마다 AI가 따로 씀 (2~13회, 1~3분). 화면을 닫아도 계속 진행
   - **💻 맥북 챗GPT로 만들기** (추천, 0원): 맥북이 켜져 있으면 맥북 일꾼(`tools/saju_worker.py`, 항상 대기)이 가져가 코덱스로 씀.
     맥북이 꺼져 있으면 대기했다가 켜는 순간 시작. 기록 `.tmp/saju_worker.log`
   - **서버 AI로 만들기**: Railway 서버의 제미나이 (1건 수십 원, 맥북 없이 됨)
   → 다 되면 왼쪽에서 고치면 오른쪽에 바로 보임 → **저장**
   - 계산값보다 과장된 표현('과다', '없다')이 있으면 '사주 계산 결과 보기'와 대조해서 고친다
4. **PDF 미리보기**로 모양 확인
5. **손님에게 보내기** → 상태가 '발송 완료'로 바뀜
- 카톡·DM으로 온 손님: 목록의 **+ 손님 직접 입력** (바로 '입금 확인' 상태로 들어감)

## 월 구독: 매일 아침 오늘의 흐름 (월 9,900원)
- 손님이 신청서에서 '매일 아침, 오늘의 흐름' 신청 → 계좌이체 → 신청 목록에서 **입금 확인** = 30일 구독 시작(이미 구독 중이면 30일 연장)
- 매일 아침 7시 이후 서버가 구독자마다 사주로 본 '오늘의 흐름'을 메일로 자동 발송 (`saju/subs.py`, 구독자 1명당 하루 AI 1회)
- 끝나기 3일 전부터 메일 하단에 연장 안내(계좌), 끝나면 '구독 종료' 메일. 손님은 메일 하단 '그만 받기'로 직접 끊을 수 있음
- 관리 화면 **구독** 메뉴: 구독자 목록, +30일, 멈춤/다시, '오늘 것 지금 보내기'
- ⚠️ 메일 설정(SMTP)이 있어야 실제로 나감
- 구독은 '첫 1회 무료' 대상이 아님

## 상품 추가·변경
- 상품·가격·목차는 `saju/products.py` 한 곳. 새 운세는 한 덩어리 추가하면 신청서·관리 화면·PDF가 자동으로 따라감
- 손님에게 보이는 'PDF 약 N쪽'은 장 분량으로 자동 계산 (A4 한 쪽 ≈ 1,500자) — 과장 표시 방지

## 결과물
손님 메일함에 `운결_이름_상품.pdf` 첨부 메일. 관리 화면에 발송 시각 기록.

## 문제가 생겼을 때
- '맥북 챗GPT로' 눌렀는데 계속 대기 → 맥북이 켜져 있고 인터넷 연결됐는지, `launchctl list | grep saju-worker` 확인. 급하면 '취소' 후 서버 AI로
- 관리 화면 경고 "메일 설정이 없어요" → `SMTP_*` 설정 전에는 메일이 실제로 안 나가고 서버 기록에만 남음
- Gmail 발송 실패 → 일반 비밀번호가 아니라 **앱 비밀번호**(myaccount.google.com/apppasswords, 2단계 인증 필요)를 써야 함
- 메일이 안 나감 → 관리 화면 '보낼 메일 N통이 맥북을 기다리는 중' 확인. 맥북이 켜져 있어야 나감. `.tmp/saju_worker.log` 확인
- PDF에 □(빈 네모)가 보임 → 글꼴에 없는 글자(한자·특수 이모지). 풀이에서 그 글자를 빼고 저장.
  PDF는 도령 분위기(밤 배경·금빛 제목). 제목용 송명 글꼴은 자주 쓰는 한글 2,350자만 있어서, 없는 글자가 섞이면 자동으로 나눔명조로 바뀜
- "이미 작성된 풀이가 있습니다" → 다시 만들면 고친 내용이 사라지므로 확인 창에서 한 번 더 누를 때만 덮어씀
- 같은 사람이 한 시간에 신청을 10번 넘게 하면 1시간 차단 (스팸 방지)
