# Workflow: 사업 지출 관리

## 목표
AI 구독·소프트웨어·광고 등 사업 지출을 구글 시트 "사업 지출 관리" 한 곳에 모은다.
- 지메일 영수증 → 자동으로 읽어서 넣기
- 카드 앱·문자·앱스토어 결제 화면 스샷 → 폰에서 드라이브 "지출_스샷" 폴더에 올리면 읽어서 넣기
- 폰 앱: 스샷 올리기, 말로 적기("오늘 캔바 15000원", "넷플릭스 매달 17000원 나가", "미드저니 해지했어") → 미리보기 확인 후 '넣기'
- 매달 나가는 고정지출은 "고정지출" 탭에 자동으로 모이고, 사장님이 상태(사용중/해지함)를 고친다

## 필요한 입력
- `credentials.json` (유튜브 업로드와 같은 구글 OAuth 클라이언트)
- `.env` 의 `GEMINI_API_KEY` (영수증 읽기)
- 구글 클라우드 프로젝트에서 켜져 있어야 하는 것: Gmail API, Google Sheets API, Google Drive API, Apps Script API
- 폰 앱은 추가로 https://script.google.com/home/usersettings 에서 'Google Apps Script API' 사용
  (꺼져 있으면 Tool 이 켜는 주소를 그대로 알려준다)

## 사용할 Tool
- `tools/finance.mjs`
- `tools/finance_app/` (폰 앱 화면·동작. 고치면 `node tools/finance.mjs app` 으로 다시 올림 — 주소 그대로)

## 순서
1. 처음 한 번: `node tools/finance.mjs login` → 사장님이 브라우저에서 허용(체크박스 전부)
2. 처음 한 번: `node tools/finance.mjs setup` → 시트와 스샷 폴더 생성, 주소는 `.env` 에 기억
3. 메일 영수증: `node tools/finance.mjs scan --months 12` (또는 `--since 2026-09-01`) 로 **먼저 몇 통·예상 비용 확인** → 사장님 OK 후 `--yes` 붙여 실행
4. 스샷: `node tools/finance.mjs shots` 로 새 장수 확인 → `--yes` 로 실행
5. 폰 앱: `node tools/finance.mjs app` → 나온 주소를 사장님 폰 홈 화면에 추가 (사파리 공유 → 홈 화면에 추가)
6. `node tools/finance.mjs summary` 로 업체별·월별 합계를 보고, 사장님께 쉬운 말로 보고
   (어디에 얼마, 겹치는 구독, 안 쓰는데 나가는 것, 줄일 수 있는 것)

## 자동 실행
- 매일 아침 8:10 `tools/finance_daily.sh` 가 메일 영수증 + 스샷 폴더를 읽어 시트에 넣는다 (`tools/finance_daily.plist`, 설치됨 2026-10-23).
- 실패하면 맥 알림이 뜬다. 기록: `.tmp/finance/daily.log`. 제미나이 하루 한도에 걸려도 다음 날 이어서 읽는다.
- 구글 OAuth 앱이 "테스트" 상태라 로그인 열쇠가 7일마다 만료된다. 만료되면 맥 알림이 뜨고, 사장님이 `tools/finance_login.command` 더블클릭 → 허용.
  ("프로덕션" 게시는 지메일 권한 때문에 사장님 소유 도메인의 홈페이지·개인정보처리방침이 필요해서 보류 — 2026-10-23 결정)

## 결과물
구글 시트 "사업 지출 관리"
- 폰 앱: 이번 달 합계·AI·고정비, 최근 6개월 월별 지출 그래프(분류별), 매달 나가는 AI 구독료 그래프
- 월별요약: 월 × 분류 합계, AI 구독 업체별 합계, 매달 고정지출 합계
- 지출내역: 날짜·업체·내용·분류·금액·통화·원화(대략)·정기결제·출처·원본ID·메모
- 고정지출: 구독별 월 금액과 상태

## 알아둘 것
- 원화(대략)는 "환율" 탭(구글 시트의 **오늘 환율**)으로 계산한다. 모든 줄이 같은 계산식이라 정렬해도 안 꼬인다. 새 통화가 나오면 환율 탭에 한 줄 추가. 결제 당시 카드 청구액과 조금 다를 수 있다.
- 같은 메일·같은 스샷은 원본ID로 걸러서 두 번 안 들어간다.
- 중복 판단 기준 (폰 앱·메일 같음): 정기결제(고정지출에 있거나 매월 결제)는 **같은 업체가 같은 달에 이미 있으면 중복**, 일회성은 같은 업체·같은 금액이 2일 안에 있으면 중복.
  - 폰 앱: 중복이면 미리보기에 "⚠ 이미 있음"으로 보여주고 안 넣는다. 사장님이 "한 번 더 결제됐어"라고 하면 넣는다.
  - 폰 앱에서 "통신비 나갔어"처럼 금액을 빼면 고정지출 금액을 쓴다.
  - 메일: 중복이면 넣되 메모에 "중복 의심" → 사장님이 확인 후 한 줄 지움.
- 결제가 아니었던 메일 목록은 `.tmp/finance/` 에 기억한다. 지워도 시트는 안 겹치고, 다시 읽는 비용만 든다.
- **제미나이 무료 등급 한도: 모델마다 하루 20번.** 메일은 25통씩 묶어 하루 약 500통까지. 한도에 걸리면 다음 날 같은 명령을 다시 실행(읽은 건 건너뜀). 폰 앱은 다른 모델(gemini-3.5-flash, `.env` 의 FINANCE_APP_MODEL 로 변경 가능)을 써서 한도가 따로.
- 비용: 제미나이 플래시 기준 메일 1통 약 0.1원 수준. 그래도 `--yes` 전에 항상 예상 비용을 사장님께 보여준다.
- 통신비(SK텔레콤 등)는 "통신비". 통신사 청구서 메일은 자동이체라 "예정 안내"여도 청구서 날짜로 넣는다 (사장님 요청 2026-10-23).
- 차비(파워큐브 전기차 충전·택시·주유·주차)는 사업 지출 "차량·교통"으로 넣는다 (사장님 결정 2026-10-23).
- 사업 지출만 넣는다. 배달·옷 같은 개인 결제는 제미나이가 뺀다. 애매하면 넣고 사장님이 지운다.

## 문제가 생겼을 때
- "구글 클라우드에서 이 기능이 꺼져 있습니다" → 알려준 주소에서 '사용' 클릭, 1~2분 뒤 다시
- "열쇠가 만료됐습니다" → 구글 테스트 상태 앱은 7일마다 만료. `login` 다시
- 폰 앱이 "권한 필요"로 안 열림 → 컴퓨터에서 같은 주소를 한 번 열어 허락
- "Apps Script 사용 설정이 꺼져 있습니다" → 안내 주소에서 켜기
- 폰 앱 키(제미나이)는 사장님 계정의 비공개 Apps Script 프로젝트 Config 파일에만 들어간다. 키를 바꾸면 `app` 다시 실행
- "허락 화면에서 빠진 항목" → 로그인 화면에서 체크박스를 전부 체크하고 다시 `login`
- 로그인 화면에서 "확인되지 않은 앱" 경고 → 사장님 본인 앱이라 정상. '고급' → '이동'
- 금액이 이상하게 들어감 → 그 줄만 시트에서 고치면 됨. 같은 업체에서 반복되면 이 문서와 Tool 의 규칙(ITEM_RULES)에 추가
