# Workflow: 유튜브 리서치 (검색 · 채널 분석 · 영상 요약)

## 목표
사장님이 준 주제나 경쟁 채널에 대해 "어떤 영상이 잘 되는지, 그 영상이 무슨 내용인지"를 숫자와 요약으로 보고한다.

## 필요한 입력
- 검색어(예: "사주 궁합") 또는 경쟁 채널(@핸들 / 채널 링크 / 채널 이름)
- 몇 개 볼지, 정렬 기준(관련도 / 조회수 / 최신) — 말이 없으면 10개, 관련도
- 요약까지 할지 여부

## 사용할 Tool
- `tools/youtube.mjs` — 검색, 채널 숫자 조회 (무료)
- ai-bridge MCP의 `gemini_watch_video` — 영상 1개 자세히 보기 (유료, 제미나이). 답 끝에 실제 사용 토큰이 붙음
- `tools/video_batch.mjs` — 영상 여러 개 차례대로 분석 (유료, 제미나이). 기본은 무료 미리보기

## 순서
1. 검색: `node tools/youtube.mjs search "검색어" 10 --order=views`
   - 정렬: `relevance`(관련도, 기본) / `views`(조회수) / `date`(최신)
2. 채널 분석: `node tools/youtube.mjs channel "@핸들" 10`
   - 구독자·총 조회·영상 수·최근 영상 평균 조회 + 최근 영상 목록
   - 평균보다 조회가 훨씬 높은 영상 = 그 채널에서 "터진" 영상 → 요약 후보
3. 요약할 영상을 고른다 (보통 조회수 상위, 또는 평균 대비 터진 영상)
4. 미리보기(무료): `node tools/video_batch.mjs .tmp/youtube_channel_….json --top=5`
   - 목록·길이 합계·예상 토큰이 나온다. 링크를 직접 넣을 때는 **따옴표로 감쌀 것** (`"https://youtu.be/…?si=…"` — 안 감싸면 터미널이 `?` 때문에 거절)
   - 정렬 `--sort=views|date|as-is`, 추가 질문 `--prompt="HSP 채널에 적용할 점"`
5. **분석 전에 사장님께 확인**: "영상 N개, 약 M분, 예상 토큰 K, 제미나이 유료" — 승인 후에만 같은 명령 끝에 `--yes`
   - 영상마다 핵심 3줄, 첫 3초 훅, 구성, 타깃, 화면 연출, 소리, 제목 패턴, 잘된/안된 이유, 따라 할 점을 JSON으로 받음
   - 하나 끝날 때마다 저장. 끊기거나 실패하면 같은 명령을 다시 돌리면 남은 것만 한다 (돈 두 번 안 나감)
   - 영상 1개를 깊게 볼 때(연출 설계도 등)는 `gemini_watch_video` 에 질문을 직접 써서 쓴다
6. 보고: 숫자 표 + 영상별 핵심 3줄 + 공통점(제목 패턴, 길이, 훅)

## 결과물
- 화면 보고 + `.tmp/youtube_search_*.json`, `.tmp/youtube_channel_*.json`, `.tmp/video_analysis_*.json`
- (예정) 구글 시트 Tool이 생기면 이 JSON을 시트 탭으로 옮긴다

## 비용·한도
- 유튜브 API: 무료. 하루 10,000점, 한국 시간 오후 4~5시쯤 다시 채워짐. 넘어도 요금 없음
  - search = 101점(하루 약 100번), channel(@핸들·ID) = 약 3점, channel(이름 검색) = 약 103점
- 제미나이 분석: 유료. 영상 1초 ≈ 300토큰(어림값) → 20분 영상 ≈ 36만 토큰. 긴 영상일수록 비쌈 → 매번 사전 승인

## 문제가 생겼을 때
- "유튜브 키가 없습니다" → .env 의 YOUTUBE_API_KEY 확인
- "키가 틀렸습니다" → 키를 다시 복사(앞뒤 공백 주의)
- "YouTube Data API v3 가 꺼져 있습니다" → 구글 클라우드에서 '사용' 클릭, 1~2분 대기
- "오늘 한도를 다 썼습니다" → 다음 날 다시. 이름 검색 대신 @핸들을 쓰면 점수 절약
- 채널을 못 찾음 → 채널 이름에서 핸들을 짐작하지 말 것(예: 이름은 "소화쌤의사주인생"인데 핸들은 @sohwa2023). 채널 페이지 주소를 그대로 받거나, 검색 결과 JSON의 `channel_id` 를 쓴다
- 조회수/좋아요가 "비공개" → 채널이 숨긴 것. 정상
- 제미나이 "503 high demand / UNAVAILABLE" → 제미나이 서버가 잠깐 붐빈 것. 요금 안 나감. video_batch 는 30초 뒤 1번 자동 재시도, MCP 는 한 번 더 시도
