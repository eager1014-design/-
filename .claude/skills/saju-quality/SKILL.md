# 사주 풀이 품질 검사

검사기: `saju/quality.py` (AI 없이 코드로 채점 — 무료)

## 검사 항목과 감점
| 등급 | 감점 | 항목 |
|---|---|---|
| ❌ 치명 | 25 | 과장(십신 그룹은 3개 이상만 '많다', 0개만 '없다'), 간지 오류(연도-간지 짝, 없는 대운), 위기 고민인데 상담전화 미안내 |
| ⚠️ 주의 | 8 | 손님 이야기 인용 부족(리포트 2번·상담 1번), 금지 문장, 본문 한자, 분량 크게 벗어남, 필수 소제목 누락 |
| ℹ️ 참고 | 2 | 분량 조금 벗어남 |

기준: **85점 이상 = 합격**, 70~84 = 고칠 점 있음, 70 미만 = 프롬프트 수정 필요.

## 1. 검사기 자체 확인 (무료, 검사기를 고쳤을 때마다)
```bash
cd saju && python3 quality.py --selftest
```
"자체 검사: 통과 ✅" 가 나와야 한다.

## 2. 이미 만든 풀이 채점 (무료)
```bash
cd saju && python3 quality.py ../.tmp/리포트.md --birth 1990-05-15 --hour 14 --minute 30 --gender female --story "고민 내용" --kind full
```
`--kind`: full(리포트) · counsel(상담) · daily · yearly · match

실서비스에서는 AI가 풀이할 때마다 서버 로그에 `[품질]` 줄이 자동으로 남는다(`interpret._result`).

## 3. 프롬프트를 고칠 때 — 전후 비교 (유료!)
1. **사장님께 먼저 묻는다**: "제미나이로 N건 생성, 약 N×수십 원". 허락 없이 실행 금지(CLAUDE.md 규칙).
2. 아래 3명의 시험 손님으로 고치기 **전** 풀이를 만들어 `.tmp/품질비교/전_*.md` 로 저장하고 채점.
3. 프롬프트 수정 후 같은 3명으로 **후** 풀이를 만들어 채점.
4. 점수표(전/후, 항목별)를 사장님께 쉬운 말로 보고. 점수가 떨어진 항목이 있으면 되돌리거나 다시 고친다.

| 시험 손님 | 생일(양력) | 성별 | 고민 분야 | 고민 |
|---|---|---|---|---|
| 지은 | 1990-05-15 14:30 서울 | 여 | career | 새 팀장이 온 뒤 회의 때 의견이 묵살돼 말을 삼키게 됨. 6개월 버틸 돈, 프리랜서 vs 이직 |
| 민호 | 1995-11-02 08:00 부산 | 남 | love | 3년 사귄 연인과 결혼 얘기만 나오면 싸움. 내가 회피하는 건지 안 맞는 건지 |
| 수아 | 1988-02-03 (시간 모름) 대전 | 여 | money | 육아휴직 끝나고 복직 vs 온라인 쇼핑몰 창업. 남편은 반대 |

(수아는 입춘 직전 생일이라 년주 경계 확인용, 시간 모름 처리 확인용)

## 4. 결과를 시스템에 반영
- 새 유형의 실수를 발견하면 → `quality.py`에 검사 항목을 추가하고 `--selftest` 예시에도 넣는다.
- 반복되는 실수는 → `interpret.py`의 `SYSTEM_PROMPT` 규칙에 금지 예시로 추가한다.
- 목표: 같은 실수는 한 번만.
