# 운결(運結) — 상담형 사주 구독 서비스

사주팔자를 계산하고, **기운을 이해시키는 해설** + **사용자의 현재 상황·고민을 반영한 방향 제시**를 제공하는
유료 구독 웹서비스입니다. 가입 즉시 **3일 무료체험**(결제수단 등록 없음)이 시작됩니다.

## 실행

```bash
cd saju
python3 server.py          # http://localhost:8000
```

Python 3.9 이상, 외부 패키지 없이 동작합니다(SQLite 내장 DB: `data/saju.db`).

### 환경변수

| 변수 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | 넣으면 Claude가 고민 내용까지 반영한 상담형 풀이 생성. 없으면 규칙 기반 해석으로 동작 |
| `CLAUDE_MODEL` | 기본 `claude-sonnet-5-5` (더 깊은 풀이는 `claude-opus-5-5`) |
| `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` | 토스페이먼츠 **자동결제(빌링)** 키. 없으면 결제 시뮬레이션(mock) 모드 |
| `PUBLIC_URL` | 결제 성공/실패 리다이렉트용 서비스 주소 (예: `https://ungyeol.kr`) |
| `SAJU_SECRET` | 로그인 쿠키 서명 키(미설정 시 `data/secret.key` 자동 생성) |

## 구조

| 파일 | 역할 |
|---|---|
| `saju_engine.py` | 만세력: 절기(태양황경 천문계산), 년·월·일·시주, 지장간, 십신, 오행, 신강약, 용신, 합충, 신살, 대운, 현재 대운·세운·월운·일진 |
| `knowledge.py` | 일간 10종, 십신, 오행, 신살, 고민 분야별 해석 관점 등 '기운 설명' 지식 베이스 |
| `interpret.py` | 상담 리포트(6장 구성)·대화형 상담·오늘의 기운 생성 (Claude 또는 규칙 기반) |
| `billing.py` | 3일 체험(`TRIAL_DAYS`), 월/연 구독, 토스 빌링키 발급·정기결제, 해지·재개, 결제 실패 유예, 갱신 스케줄러 |
| `server.py` | HTTP 서버·API·인증(PBKDF2 + 서명 쿠키)·이용권한 체크 |
| `static/` | 화면 (랜딩, 가입, 사주·상황 입력, 원국 해설, 리포트, 상담, 오늘의 운, 구독, 내 구독) |

## 무료 / 유료 구분

- **무료(체험 종료 후에도)**: 원국표, 일간 해설, 오행·십신 분포와 설명, 대운표, 현재 운 요약 → 사주를 '이해'하는 부분
- **구독(체험 3일 포함)**: 고민 반영 심층 리포트(매월 갱신), 1:1 고민 상담(일 20회), 오늘의 기운, 기록 보관

## 계산 기준

- 년주는 입춘, 월주는 12절 기준. 절기 시각 오차는 ±5분 수준(절입 직전·직후 출생은 확인 권장).
- 시주는 출생 지역 경도로 지방평균태양시 보정(서울 약 −32분), 1954~61년 UTC+8:30, 1955~60·1987~88년 서머타임 반영.
- 지방시 23시 이후 출생은 다음 날 자시로 처리. 현재 양력 생일만 지원(음력 변환은 추가 예정).

## 실서비스 전 체크리스트

1. 토스페이먼츠 **자동결제(빌링) 계약** 후 키 설정 → 카드 등록·정기결제가 실제로 진행됨
2. **전자상거래법(구독경제 규정)**: 무료→유료 전환 7일 전 고지, 가격 변경 고지, 쉬운 해지 — 체험 종료 안내 메일/알림톡 발송 기능 추가 필요
3. 이용약관·개인정보처리방침 페이지 작성 (생년월일·고민 내용은 민감할 수 있으므로 보관 기간·암호화 명시)
4. HTTPS 뒤에서 실행(쿠키에 `Secure` 추가), `/api/dev/expire-trial`은 mock 모드에서만 열림
5. 음력 생일 입력, 이메일 인증·비밀번호 재설정, 궁합 등 추가 기능 검토
