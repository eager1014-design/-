# 일레븐랩스 녹음 대본 — ep02s 쇼츠 '예민한 내 사주를 직접 풀어봤더니'

## 설정
- 목소리: 천성준 (사장님 복제 목소리), 모델 Eleven v3
- 대괄호 `[ ]` 는 말투 지시라 읽히지 않음 (소리로 읽히면 그 태그만 지우고 다시 생성)
- 아래 블록을 **한 번에** 생성 (톤이 처음부터 끝까지 일정). 약 402자
- 문단 하나 = 장면 하나. 문단 사이 쉼으로 장면을 자르니 문단을 합치지 말 것

## 받은 파일
mp3 다운로드 → 이름을 `voice_full.mp3` 로 → 이 폴더(`video/public/episodes/ep02s-born-sensitive/`)에 넣기 → 클로드에게 "넣었어"

---

```
[quiet, sincere] 예민한 거, 저는 제 성격 탓인 줄 알았어요.

[curious] 그런데 쌍둥이 이천팔백여 명을 조사했더니, 사람마다 예민한 정도가 다른 이유의 사십칠 퍼센트가 유전이었어요.

[gently] 그럼 저는 어떤 결로 타고났을까. 그래서 제 사주를 펼쳐봤어요.

[warm, explaining] 사주는 태어난 해, 달, 날, 시. 네 기둥에 두 글자씩, 그래서 여덟 글자, 팔자예요. 그중 태어난 날의 윗글자가 바로 나예요.

글자마다 나무, 불, 흙, 쇠, 물 중 하나의 기운이 있는데, 제 글자는 물이었어요.

[softly] 계수는 비, 이슬, 우물물이래요. 조용히 스며들어서 남의 감정까지 흡수하는 물. 그래서 그렇게 쉽게 지쳤던 거예요.

[slower, sincere] 고쳐야 할 성격이 아니라, 다루면 되는 기질이었어요.

[warm, smiling] 당신은 어떤 글자로 태어났을까요? 생년월일만 넣으면 무료로 볼 수 있게 제가 직접 만들어 뒀어요. 링크는 고정 댓글에 있어요.
```
