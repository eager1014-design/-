## 속도
장면당 평균 3~4초로 매우 빠르고 군더더기 없는 속도감. 말을 쉬지 않고 연속해서 몰아치며 그래픽 화면과 실물 화자를 빠르게 번갈아 보여주어 몰입도를 높인다.

## 목소리
실제 사람 음성, 또박또박하고 속도감 있는 존댓말(해요체), 새로운 유용한 툴을 발견해 신나서 공유하는 열정적이고 친근한 톤

## 화면 글씨
화면 하단 중앙에 깔끔한 검은 테두리의 굵은 흰색 자막을 한 줄씩 배치하고 핵심 단어에는 컬러(노란색/연두색) 강조를 적용함. 상단에는 설명 보조용 UI 인포그래픽 카드를 배치.

## 끝맺음
자체 제작 가이드북을 미끼로 걸고 '팔로우 후 댓글에 특정 키워드(법정) 입력 시 DM 자동 발송'을 유도하는 다이렉트 리드 수집형 콜투액션(CTA)

## 따라 할 점
- 상단 60%에는 아기자기한 도트 UI/웹 화면 그래픽을 띄우고, 하단 40%에는 핀마이크를 든 화자를 배치하는 2단 분할 레이아웃
- 공감 가는 일상적 문제(AI가 칭찬만 해서 객관성이 없음)를 먼저 건드린 뒤 기발한 도구로 해소해 주는 문제-해결 스토리텔링
- 복잡한 다중 에이전트(Multi-agent) 시스템을 '검사-변호인-배심원-판사'라는 대중적인 법정 메타포로 단순화하여 직관적으로 이해시키는 비유 연출
- 댓글 작성 시 DM 자동 발송되는 챗봇 워크플로우를 실제 모바일 UI 애니메이션으로 보여주어 댓글 참여 전환율을 극대화하는 엔딩
